# Pomodoro (plugin de exemplo)

Mostra um cartão com o tempo de foco/pausa na interface da Tera e faz ela avisar quando
cada fase acaba. Serve de modelo pra plugins: `teracota-plugin.json` (manifesto) e
`main.js` (roda isolado, só com a API `tera`).

Instalar: copie esta pasta pra pasta de plugins (Ajustes → Plugins → "Abrir a pasta de
plugins"), clique em "Procurar de novo" e ligue o plugin (a Tera mostra as permissões).

Guia completo: `docs/dev/plugins.md`.
