        No celular
        
Leia o QR e acompanhe do sofá.

        
Igual ao WhatsApp Web, com os papéis trocados: o PC trabalha, o celular acompanha. Na rede de casa, cifrado de ponta a ponta com a chave que vai no QR (ela nunca passa pela rede), e nada conecta sem o seu "sim" no PC.

        
      

    


    
    

      

        Skins
        
Monte a sua Tera.

        
O Skin Studio monta e anima personagens em camadas (pivôs, poses, expressões, piscada, fala, passos) com o mesmo motor do app. O tera-skin valida e renderiza uma folha de conferência — feito pra trabalhar junto com agentes de código.

        

        

        
        
        
# uma skin nova, já funcionando
pnpm skin new minha-tera --nome "Minha Tera"
pnpm skin studio minha-tera     # editor visual
pnpm skin render minha-tera     # folha de conferência

// main.js — roda isolado, só com a API `tera`
let fim = Date.now() + tera.settings.foco * 60_000;

setInterval(() => {
  const falta = fim - Date.now();
  tera.card.set('relogio', {
    title: `Foco · ${mmss(falta)}`,
    progress: 1 - falta / total,
  });
  if (falta <= 0) tera.say('Pausa! 🍅');
}, 1000);

      

        Plugins e outras IAs
        
Ela cresce com você.

        
Plugins são uma pasta com um manifesto e um JS que roda isolado: sem acesso ao sistema, rede só nos sites declarados, e cada permissão aprovada por você. Cartões, falas, sessões de outros agentes, limites de uso — o núcleo da Tera não conhece nenhuma IA pelo nome.
